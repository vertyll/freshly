# Glossary

Terms the documentation uses, the standard each one comes from, and where it is explained.

| Term                    | Meaning                                                                                                              | Standard                                                                                                                                           | Explained in                                                                                                                                            |
|-------------------------|----------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| Access token, audience  | The JWT every request is authorized by, accepted only with this API as its audience.                                 | [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519#section-4.1.3) §4.1.3                                                                            | [auth: The API accepts only its own tokens](freshly-backend/modules/auth/README.md#the-api-accepts-only-its-own-tokens)                                 |
| Anti-corruption layer   | A module's own adapter that translates another module's API into its own words.                                      | —                                                                                                                                                  | [Hexagonal Layering: The rule, between bounded contexts](freshly-backend/docs/hexagonal-layering.md#the-rule-between-bounded-contexts)                  |
| Authorization code flow | Sign-in by redirecting to Keycloak and exchanging the returned code on the server.                                   | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-4.1) §4.1                                                                                | [auth: The flow](freshly-backend/modules/auth/README.md#the-flow)                                                                                       |
| BFF                     | The back-end signs the user in and keeps the tokens; the browser holds only a session cookie.                        | —                                                                                                                                                  | [auth: The flow](freshly-backend/modules/auth/README.md#the-flow)                                                                                       |
| Bounded context         | A module with its own model, ports and persistence: `auth`, `useraccess`, `permission`, `translation`, `airquality`. | —                                                                                                                                                  | [Hexagonal Layering: The rule, between bounded contexts](freshly-backend/docs/hexagonal-layering.md#the-rule-between-bounded-contexts)                  |
| Default, override       | The module's text in code, rewritten at every start-up, and an administrator's text, never touched by a deployment.  | —                                                                                                                                                  | [Translations: The two layers](freshly-backend/docs/translations.md#the-two-layers)                                                                     |
| ETag, `If-Match`        | Version of a resource, and the condition a write carries so a stale edit is refused.                                 | [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110#section-8.8.3) §8.8.3, [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110#section-13.1.1) §13.1.1 | [Hexagonal Layering: Optimistic locking → VersionGuard](freshly-backend/docs/hexagonal-layering.md#optimistic-locking--versionguard)                    |
| GIOŚ                    | The Polish Chief Inspectorate of Environmental Protection, the source of air quality readings.                       | [GIOŚ API](https://powietrze.gios.gov.pl/pjp/content/api)                                                                                          | [airquality: The model](freshly-backend/modules/airquality/README.md#the-model)                                                                         |
| ICU MessageFormat       | The message syntax, with plural rules for Polish.                                                                    | [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/)                                                            | [Translations: The message format is ICU](freshly-backend/docs/translations.md#the-message-format-is-icu)                                               |
| Permission              | What a role may do, declared by the module that enforces it.                                                         | —                                                                                                                                                  | [permission: Where a permission is declared](freshly-backend/modules/permission/README.md#where-a-permission-is-declared)                               |
| PKCE                    | A one-time secret that ties the returned code to the browser that started the sign-in.                               | [RFC 7636](https://www.rfc-editor.org/rfc/rfc7636)                                                                                                 | [auth: State and PKCE are tied to the browser that started](freshly-backend/modules/auth/README.md#state-and-pkce-are-tied-to-the-browser-that-started) |
| Port, adapter           | An interface a module's application layer owns, and its implementation in infrastructure.                            | —                                                                                                                                                  | [Hexagonal Layering: The rule, inside one bounded context](freshly-backend/docs/hexagonal-layering.md#the-rule-inside-one-bounded-context)              |
| Problem document        | The JSON body of every refusal, with a key in `code` and the resolved text in `detail`.                              | [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)                                                                                                 | [Translations: Field validation carries keys too](freshly-backend/docs/translations.md#field-validation-carries-keys-too)                               |
| Published language      | A shared vocabulary every module may use, such as `shared-authz`.                                                    | —                                                                                                                                                  | [Shared modules: shared-authz is a Published Language](freshly-backend/docs/shared-modules.md#shared-authz-is-a-published-language)                     |
| `Sec-Fetch-Site`        | Header the browser sends to say where a request came from; a cross-site write gets no token.                         | [Fetch Metadata](https://www.w3.org/TR/fetch-metadata/) (W3C)                                                                                      | [auth: Cross-site writes get no token](freshly-backend/modules/auth/README.md#cross-site-writes-get-no-token)                                           |
| Single-flight refresh   | One refresh per refresh token, across replicas.                                                                      | —                                                                                                                                                  | [auth: One refresh per refresh token](freshly-backend/modules/auth/README.md#one-refresh-per-refresh-token)                                             |
| Stale override          | An override whose default has changed since it was written.                                                          | —                                                                                                                                                  | [Translations: Staleness](freshly-backend/docs/translations.md#staleness)                                                                               |
