# Glossary

Every term the documentation uses without defining it on the spot, and where it is explained. The specifications behind
them are in [STANDARDS.md](STANDARDS.md).

| Term                  | Meaning                                                                                                              | Explained in                                                                                                                                       |
|-----------------------|----------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| Access token          | The JWT every request is authorized by, accepted only with this API as its audience.                                 | [Token audience](freshly-backend/modules/auth/docs/mechanisms/token-audience.md)                                                                   |
| Air quality level     | A step of the official index scale, 0 to 5, read from the value GIOŚ sends.                                          | [GIOŚ integration](freshly-backend/modules/airquality/docs/mechanisms/gios-integration.md)                                                         |
| Analysis window       | The number of days a statistic or ranking covers; `ofDays` clamps, `ofDaysStrict` refuses.                           | [airquality: Bounds are value objects](freshly-backend/modules/airquality/README.md#bounds-are-value-objects)                                      |
| Anti-corruption layer | A module's own adapter that translates another module's or GIOŚ's model into its own words.                          | [Hexagonal Layering: The rule, between bounded contexts](freshly-backend/docs/hexagonal-layering.md#the-rule-between-bounded-contexts)             |
| BFF                   | The back-end signs the user in and keeps the tokens; the browser holds only `FRESHLY_SESSION`.                       | [auth: The flow](freshly-backend/modules/auth/README.md#the-flow)                                                                                  |
| Bounded context       | A module with its own model, ports and persistence: `auth`, `useraccess`, `permission`, `translation`, `airquality`. | [Hexagonal Layering: The rule, between bounded contexts](freshly-backend/docs/hexagonal-layering.md#the-rule-between-bounded-contexts)             |
| Caller roles          | The set of role names an authorization decision is made from.                                                        | [permission: What the decision is made from](freshly-backend/modules/permission/README.md#what-the-decision-is-made-from)                          |
| Default               | A module's text declared in code, rewritten at every start.                                                          | [Translation catalog: The two layers](freshly-backend/docs/mechanisms/translation-catalog.md#the-two-layers)                                       |
| Dominant level        | The most frequent level in a window; no data gives no level, and a tie goes to the worse one.                        | [airquality: The statistics round the unreassuring way](freshly-backend/modules/airquality/README.md#the-statistics-round-the-unreassuring-way)    |
| GIOŚ                  | The Polish Chief Inspectorate of Environmental Protection, the source of the readings.                               | [airquality](freshly-backend/modules/airquality/README.md)                                                                                         |
| Measurement           | One station's readings at one hour; immutable, identified by station and timestamp.                                  | [airquality: AirQualityMeasurement is immutable](freshly-backend/modules/airquality/README.md#airqualitymeasurement-is-immutable)                  |
| Message key           | A key of the translation catalog; a problem document carries it in `code`.                                           | [Error responses](freshly-backend/docs/mechanisms/error-responses.md)                                                                              |
| Orphan key            | A stored key no module declares any more.                                                                            | [Translation catalog: Keys nobody declares any more](freshly-backend/docs/mechanisms/translation-catalog.md#keys-nobody-declares-any-more)         |
| Override              | An administrator's text for a key, never touched by a deployment.                                                    | [Translation catalog: The two layers](freshly-backend/docs/mechanisms/translation-catalog.md#the-two-layers)                                       |
| Permission            | What a role may do, declared by the module that enforces it.                                                         | [permission: Where a permission is declared](freshly-backend/modules/permission/README.md#where-a-permission-is-declared)                          |
| PKCE                  | A one-time secret binding the returned code to the browser that started the sign-in.                                 | [Sign-in state](freshly-backend/modules/auth/docs/mechanisms/sign-in-state.md)                                                                     |
| Pollutant             | A tracked substance, such as PM10 or NO2; readings are a map keyed by it.                                            | [airquality: Readings are a map, not six nullable fields](freshly-backend/modules/airquality/README.md#readings-are-a-map-not-six-nullable-fields) |
| Port, adapter         | An interface a module's application layer owns, and its implementation in infrastructure.                            | [Hexagonal Layering: The rule, inside one bounded context](freshly-backend/docs/hexagonal-layering.md#the-rule-inside-one-bounded-context)         |
| Problem document      | The JSON body of every refusal: a key in `code` and the text resolved for the reader in `detail`.                    | [Error responses](freshly-backend/docs/mechanisms/error-responses.md)                                                                              |
| Provisioning          | Creating the local user at the first sign-in; `auth` decides, `useraccess` stores.                                   | [useraccess: What it deliberately does not own](freshly-backend/modules/useraccess/README.md#what-it-deliberately-does-not-own)                    |
| Published language    | A shared vocabulary every module may use, such as `shared-authz`.                                                    | [Shared modules: shared-authz is a Published Language](freshly-backend/docs/shared-modules.md#shared-authz-is-a-published-language)                |
| Role authority        | The document naming the permissions one role carries.                                                                | [permission](freshly-backend/modules/permission/README.md)                                                                                         |
| Single-flight refresh | One refresh per refresh token, across replicas.                                                                      | [Token refresh](freshly-backend/modules/auth/docs/mechanisms/token-refresh.md)                                                                     |
| Stale override        | An override whose default has changed since it was written.                                                          | [Translation catalog: Staleness](freshly-backend/docs/mechanisms/translation-catalog.md#staleness)                                                 |
| `SystemUser`          | A person's standing in the application: active or not, and their roles.                                              | [useraccess: What it owns](freshly-backend/modules/useraccess/README.md#what-it-owns)                                                              |
| `VersionGuard`        | The comparison of a submitted version with the stored one, in `shared-lang`; `ETagUtil` handles the header.          | [Hexagonal Layering: Optimistic locking → VersionGuard](freshly-backend/docs/hexagonal-layering.md#optimistic-locking--versionguard)               |
